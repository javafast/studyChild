# 键盘大冒险 🎹

给小朋友的网页版拼音 + 英文字母键盘学习工具。纯前端、零依赖、可离线使用。

## 使用

- 方式一：直接双击 `index.html` 用浏览器打开
- 方式二：在项目目录运行 `python3 -m http.server 8765`，打开 http://127.0.0.1:8765

## 首页结构

首页进来先是「乐园」选择（四宫格卡片），不是平铺的关卡列表：

- 🐼 **拼音乐园** = 拼音打字轨 + 语文识字轨
- 🍎 **单词乐园** = 字母触摸键轨 + 单词挑战轨
- 🐸 **游戏乐园** = 青蛙过河（字母/拼音/单词三种模式选择）

点进乐园后才会看到该乐园下的 tab 切换和章节网格，点「← 乐园」返回首页选择。当前选的乐园/tab 会存 localStorage，刷新页面不会跳回首页。

右下角 ⚙️ 悬浮按钮是设置面板，收纳了按键声音选择、音效开关、自由选关、清空进度这几项配置/危险操作，不占首页主界面。

## 功能

- **章节**：字母轨 16 关 + 拼音轨 7 关 + 单词轨 5 关 + 语文识字四个学期（一年级上 18 关、一年级下 28 关、二年级上 27 关、二年级下 29 关），通过上一关解锁下一关
- **语文识字**：按年级和学期选择教材，覆盖一、二年级共四册课本，逐课按课文真实生字表学习汉字、拼音和组词（三年级起显示"即将开放"）
- **按键提示**：虚拟键盘按四指分区着色，下一个要按的键橙色描边闪烁放大
- **动态指法图**：指法讲解页用同色键盘与双手联动演示，也可按键或点击查看对应手指
- **发音**：按键读音分「拼音/英文」两套独立逻辑，「自动人声」按当前所在乐园/关卡整体切换一次（进关卡时定下来，不再逐键猜测），也可在设置里手动固定读拼音或英文
- **练习反馈**：对错音效、按键绿/红闪、连击计数、实时正确率与进度条、三星结算（按正确率评星，结算页展示速度/用时/最高连击/弱键）
- **三星连闯**：获得三星且还有下一关时，结算页倒计时 3 秒后自动进入下一关
- **幽灵竞速**：通关过一次后，同一关会出现 👻 最佳纪录进度条，和自己的最快成绩赛跑，破纪录有提示
- **自适应复习**：全局错误率高的键会在后续关卡自动加权重现，练熟了自然减少
- **三课一复习**：所有年级的语文教材每完成三课自动插入复习关，合并并打乱前三课生字重新输入
- **年级随机打字**：汇总当前年级上下册生字，每轮去重后随机抽取 50 个，并可关闭键盘按键提示
- **打卡与徽章**：每天练习自动打卡（首页显示连续天数），13 枚成就徽章在「我的徽章」里收集
- **青蛙过河**：字母/拼音/单词三种模式小游戏，可选分支河道与隐藏键盘挑战，战绩计入家长统计
- **多娃档案**：右上角可切换/添加/删除小朋友档案，每个孩子的进度互相独立
- **进度记录**：localStorage 保存每关星星、最佳正确率/速度/用时、每键对错统计、游戏战绩、打卡与徽章；设置面板「家长统计」可看弱键榜

## 自定义

- 增删词语或关卡：`js/data.js`
- 乐园分组（哪些轨道属于拼音乐园/单词乐园）：`js/app.js`（`landOfTrack()`）
- 星星判定阈值、关卡长度：`js/app.js`（`finish()` 内）
- 弱键加权强度：`js/app.js`（`keyWeight()`）
- 徽章列表：`js/app.js`（`BADGES`）
- 样式与配色：`css/style.css`

## 小技巧

- `Esc` 练习中返回所在乐园的章节列表（不会跳回首页乐园选择）；`Backspace` 拼音模式可退格
- 直链进入章节：`#p=letters:0`、`#p=pinyin:2`、`#p=chinese:0`，会自动定位到对应乐园
- `?still=1` 关闭动画（截图 / 减少动态效果）
